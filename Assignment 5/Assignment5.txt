What I Learned:
Array lists are Java's equivalent of Python's lists in the sense that they are more flexible than arrays. 
Arrays require a specified size when they are created, while array lists have a default size of 10 and automatically resize as more objects are added.
In the cave game project, array lists are used to store all the players and goblins for other functions to loop through.
More specifically, the game uses lists which differ from array lists as lists aren't actually objects and are instead interfaces which use array lists as a base.
The advantage of using these over arrays is that they allow the game to spawn bigger amounts of goblins each round without having to make new arrays.
